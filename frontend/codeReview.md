## 요청 목표

내 프로젝트의 일부 코드베이스를 대상으로, 아래 기준에 부합하는 "잘 작성된 코드"를 찾아서 분석해줘.
"평가 기준"에 1~15번 항목에 해당되는 요소들이 있는지 확인하고, 있으면 그 번호 아래에 근거를 작성해줘.
그리고 "답변 포맷"에 따라서 뭐를 잘했는지 작성해줘.

## 평가 기준 (1~2년차 FE 개발자 기준)

1. **선언적 프로그래밍 실천**: 복잡한 상태나 흐름을 선언형 코드로 정리한 부분
2. **서버/클라이언트 경계 이해 및 활용**: SSR, 초기 데이터 prefetch, dehydrate/hydrate 처리 적용한 부분
3. **타입 안정성 강화**: props, 유틸 함수에 타입 안전성을 적용하거나 타입 자동 생성 시스템을 구축한 부분
4. **UX를 개선하기 위한 퍼포먼스 최적화**: lazy loading, dynamic import, 리렌더링 최적화 등을 적용한 부분
5. **에러 핸들링 체계화**: 서버/네트워크 오류를 사용자 관점에서 graceful하게 처리한 부분
6. **CI/CD 및 빌드 최적화 경험**: 빌드, 테스트, 배포 시간을 단축하거나 병렬 처리 최적화한 부분
7. **테스트 문화 도입 및 실천**: Vitest, Playwright 등을 이용해 테스트 코드를 작성하고 적용한 부분
8. **컴포넌트/유틸리티 재사용성 강화**: 공통화하거나 재사용성 높은 구조로 작성한 부분
9. **에러 모니터링 환경 구축**: Sentry 등으로 에러 로깅 및 모니터링을 설정한 부분
10. **PR 프로세스 개선 경험**: PR 자동화, 라벨링, 체계적 리뷰 프로세스 도입 경험
11. **디자인 시스템 구현 또는 컴포넌트화**: UI 일관성과 재사용성을 높이기 위해 디자인 시스템 또는 공통 컴포넌트를 설계한 부분
12. **API 통신 안정성 확보**: API 에러 처리, 재시도 로직, 상태 관리 일관성 확보 등 안정성을 고려한 구현
13. **상태 관리 최적화**: React Query, Zustand, Recoil 등을 활용해 복잡한 상태를 효과적으로 관리한 부분
14. **SEO 최적화 고려**: SSR 적용, 메타 태그 관리 등을 통해 검색 엔진 최적화를 고려한 부분
15. **애니메이션 및 인터랙션 고도화**: Framer Motion 등 라이브러리를 활용해 자연스러운 사용자 인터랙션을 구현한 부분

## 답변 포맷

아래 포맷을 반드시 따라 작성해줘.

### [좋은 코드 포인트]

- **파일명**: (예시: apps/web/src/components/Button.tsx)
- **코드 스니펫**:
  ```tsx
  // 코드 일부를 보여줘
  ```
- **칭찬 포인트**:
  - 어떤 기준에 부합하는지 (ex: 선언적 프로그래밍 잘 적용)
  - 왜 좋은 코드인지 (구체적 설명)
- **추가 개선 가능성 (선택사항)**:
  - 더 개선할 수 있는 부분이 있다면 제안

## 추가 지시사항

- 모든 파일을 다 스캔하지 말고, 특히 인상 깊었던 5개 정도만 선정해줘.
- 단순한 칭찬 대신 '구체적 원칙 + 이유'를 포함해서 작성해줘.
- 필요시, 각 기준 항목별로 베스트 사례를 각각 하나씩 선정해줘도 좋아.
